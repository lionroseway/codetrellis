CodeTrellis 0.1.17 is a reliability and trust release. It fixes 37 bugs found by testing the whole app end to end, makes permissions yours alone to grant, and makes the app quieter. It is a desktop release: there is no new phone build this time, and your paired phone keeps working.

## ⚠️ Before you start

- **Only you can grant permissions now, and only from the CodeTrellis window.** What agents may do, which projects they can reach, what a paired phone may do, and whether phones can connect: an agent or a phone asking to change any of these is refused and told where you change it. Everything else in Settings still works from anywhere.
- **Agents can no longer delete plans.** An agent asks instead: you see the plans, its reason and what deleting does, and nothing is deleted until you type the plan's name. Your own delete buttons work as before.
- **New plans follow your Shared / Local default.** Plans you make in the app or on your phone used to stay on your machine even when the default said Shared. Now a new plan is written into `.codetrellis/plans/` as soon as it has a name, ready to commit. To keep new plans on this machine, set **Settings → Plans → Default visibility** to Local.
- **Scripts that used the old task routes** (`/api/tasks/…`, `/api/plans/:uid/tasks…`) need updating to the item routes. The app stopped using them long ago.
- **No phone update needed.** Pairing hasn't changed since 0.1.14. The phone fixes below are on the desktop side, so they work with the companion you already have. The phone-screen additions listed under Phone arrive with the next companion build.

## 🔐 Trust

- **Permissions are yours alone to grant**, as above. Opening the app window is the only way in; a command-line way is planned.
- **Every record says who made it.** Items, comments, budgets, criteria, system docs and imported plans made by an agent now name that agent — Claude Code, Cursor and so on — rather than a generic "agent", and are never recorded as yours.
- **Changes an agent makes to your guardrails are flagged until you've seen them.** When an agent raises a plan's budget or freezes or unfreezes the project, a flag stays on the budget chip or freeze bar, with who did what, until you mark it Seen. That includes lifting a freeze, which used to leave no trace.
- **Answers to a phone's question say who answered.** If an agent answers a question that was put to you, the phone is told it was the agent.
- **Shared audio goes only to devices you've allowed** to receive your microphone.
- **The phone link is hardened further.**
- **The update check is the only request the app makes on its own,** and turning it off in Settings → Updates is now tested to mean no request at all.

## 🧭 Plans and review

- **Your diff baseline survives a restart.** It used to be re-taken from whatever was on disk at launch, so "changes since baseline" quietly became "changes since this morning", and a commit you pinned was forgotten.
- **Renaming a plan keeps it connected to its files.** Before, a renamed plan stopped writing to the repo, and deleting it later left its folder behind to come back on the next pull. A plan's folder follows its title until it has been committed; after that it keeps its name.
- **A deleted plan stays deleted.** Its folder no longer reappears a moment later.
- **Item changes reach the repo straight away.** Adding, editing, moving or deleting an item used to wait until something else about the plan changed.
- **Items can't disappear from the tree.** Moving an item under one of its own sub-items, or under an item in another plan, is refused; before, both vanished.
- **Reconciling a deviation acts on the right plan,** and a deviation that doesn't exist is refused rather than reported as resolved.
- **Plan history search finds every matching commit** and the files each one touched.
- **A teammate's first channel messages on a shared plan show up** without waiting for something else to change.
- **"Add to plan"** from the code reader adds the lines to the task you pick, and a new plan made from it shows up.

## 🗺 Graph and code

- **The live graph stays right between scans.** Editing a file no longer drops its connections, a new file gets its connections, and a deleted file leaves the graph.
- **Worktrees work properly:** the branch shows, branches and sibling worktrees are listed, and plan-file merge conflicts are detected.
- **Agents' graph questions answer correctly** whether they give a project-relative or an absolute path.
- **The baseline is labelled honestly:** "abc1234 + uncommitted changes" when it includes uncommitted work, and "Pin current HEAD" pins HEAD itself.

## 📱 Phone

- **Editing an item on the phone saves.** Every change from the phone's editor — body, status, title — used to fail silently.
- **What you do on the phone shows on the desktop straight away:** plans, items, comments, links, channel posts and system docs.
- **Two phones stay in step,** and a connected phone no longer receives a stream of empty updates.
- **Plan and item statuses are checked,** so a phone or script can't store a status nothing understands.
- **Next companion build:** a plan's deviations listed again, and cards for the plan's budget and the project's freeze, with the agent changes to mark Seen. These are in the source; they reach your phone with the next companion build.

## 🎛 Quieter and clearer

- **The change summary on the graph is one line** — "Working tree · 8 changes" — and opens its breakdown when you click it. It used to sit over the graph's toolbar.
- **Plan readiness says what's left in words** ("1 to do before hand-off") instead of a red percentage on every new draft.
- **The plan panel names what it sees** ("Claude Code running") rather than "Agent active" beside a top bar saying "No agents".
- **Settings speak plainly.** A refused value names the field ("The MCP port must be a number from 1024 to 65535"), Power says what it's doing, Logs says when this build writes no log file, and the modal no longer changes height between sections.
- **Smaller things:** the plan header no longer repeats itself, item chips use icons rather than emoji, the branch chip stays on one line, the folder picker opens beside your project, and the Brief says "your agent" rather than naming one.

## 🛠 Fixes

- A refused update download no longer blocks every later one until restart.
- Settings you save are checked on the way in, so a bad value is refused with the reason instead of quietly becoming the default at the next restart.
- Waiting on the agent pane can't strand an agent: two agents asking at once each get their answer, dismissing cards releases whoever was waiting, and waiting on a card that doesn't exist says so at once.
- A CSV cell an agent cites can be read back, and a quoted comma no longer counts as a column.
- Audio capture settings are checked, so a bad value can't make the buffer grow without limit.
- Freeze settings are checked: "no" no longer freezes the project, and an end date that isn't a date is refused.
- Agent tools that took a plan, item or file on trust now refuse one that doesn't exist, instead of reporting success.
- Plan and item search treats `%` and `_` as characters.
- `get_logs` says when file logging isn't running instead of reporting "no entries".

## Known limits

- **A second checkout of the same repository** (a worktree or another clone) takes the first one's system docs when it's scanned. Working across checkouts is the next piece of work.
- **Once a plan's folder has been committed, it keeps its name** when you rename the plan, so that teammates' copies don't break.
- **Changing permissions has no command-line way yet;** use the app window.
- **Windows portable `.exe`:** an agent's connection starts only while CodeTrellis is open, and must be re-added after each update. Use the Windows installer for agent work.
- **Sign-offs stay on the machine where they were made.** Plan files carry the criteria but never the decisions.
- **Linux AppImage** runs without Chromium's sandbox. Prefer the `.deb` or `.rpm` where you have the choice.
- **Windows** builds are not code-signed, so SmartScreen may warn once.

## First launch

- **macOS:** drag to Applications and open. If you see "app is damaged" (usually because the download lost its attributes), run `xattr -cr /Applications/CodeTrellis.app` once.
- **Windows:** SmartScreen may warn once. Choose "More info", then "Run anyway".
- **Linux (AppImage):** `chmod +x CodeTrellis-0.1.17-x86_64.AppImage && ./CodeTrellis-0.1.17-x86_64.AppImage`
- **Linux (.deb / .rpm):** `sudo apt install ./codetrellis_*.deb` or `sudo dnf install ./codetrellis-*.rpm`
