CodeTrellis 0.1.19 is a fix release for what running everything on a Mac turned up after 0.1.18: teammates' channel messages that went missing after a pull, a Diff button you couldn't click, and a top bar that lost its controls in a repository with many branches. Desktop only: the phone companion is unchanged.

## ⚠️ Before you start

- **The phone companion stays at 0.1.18.** Nothing in this release touches it, and pairing hasn't changed since 0.1.14. **Android:** keep `CodeTrellis-Companion-0.1.18.apk`, attached to [v0.1.18](https://github.com/lionroseway/codetrellis-releases/releases/tag/v0.1.18). **iOS:** TestFlight build 28.

## 🛠 Fixes

- **A teammate's channel messages arrive after a pull, on macOS.** When a pull brought new messages to several plans at once, the Mac app saw the first two plans' and missed the rest until something else touched those plans. On macOS CodeTrellis now watches each folder tree with the system's own file events, which report every folder and file in a burst.
- **Watching a large repository no longer runs short of file handles on macOS.** The same change watches each tree with one handle instead of one per file, so the limit named in 0.1.18's notes is gone.
- **Code mode's Diff button can be clicked.** Invisible resize handles from the layout underneath sat on top of code mode and took the clicks. Depending on the window size it could be other buttons too.
- **The top bar fits in a repository with many branches.** Lines of work used to show one full-width chip per recent branch, so at 1280px the project tab, its branch chip and **+** were squeezed out, and at the narrowest window Settings went off the edge. The strip now shows as many chips as fit, with the rest behind **+N**. Below 1536px, Connect Agent, the agents count and devices show as icons with their tooltips.

## Known limits

- **Breakpoints detect and report a write that got past them; they don't undo it.**
- **Google Drive and Dropbox shared folders aren't detected** as shared plans folders. OneDrive and SharePoint are.
- **The CLI is installed from a checkout.**
- **Windows portable `.exe`:** an agent's connection starts only while CodeTrellis is open, and must be re-added after each update. Use the Windows installer for agent work.
- **Linux AppImage** runs without Chromium's sandbox. Prefer the `.deb` or `.rpm` where you have the choice.
- **Windows** builds aren't code-signed, so SmartScreen may warn once.

## First launch

- **macOS:** drag to Applications and open. If you see "app is damaged" (usually because the download lost its attributes), run `xattr -cr /Applications/CodeTrellis.app` once.
- **Windows:** SmartScreen may warn once. Choose "More info", then "Run anyway".
- **Linux (AppImage):** `chmod +x CodeTrellis-0.1.19-x86_64.AppImage && ./CodeTrellis-0.1.19-x86_64.AppImage`
- **Linux (.deb / .rpm):** `sudo apt install ./codetrellis_*.deb` or `sudo dnf install ./codetrellis-*.rpm`
