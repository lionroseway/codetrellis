CodeTrellis 0.1.16 is a big release. Agents now show their work against acceptance criteria that a person signs off, and CodeTrellis works on documents and spreadsheets as well as code. It also tightens how CodeTrellis reads files on your machine, so everyone on 0.1.15 should upgrade.

## ⚠️ Before you start

- **Existing plans may now wait for your sign-off.**
  - A task whose description has an `## Acceptance criteria` section gets those lines as criteria, and a person has to approve them. The description itself is not changed.
  - A task marked "needs approval" gets a "Reviewed and approved" criterion instead.
  - Once such a task is done, the next task waits until a person approves.
- **Agents can no longer clear an approval gate.** The old approve-gate tool now refuses, and tells the agent to submit evidence against the task's criteria instead. Only a person decides.
- **Connect your agents again, once.**
  - Agent configs copied from 0.1.14 or 0.1.15 lacked the credential CodeTrellis requires, so those agents were refused.
  - If you fixed that by pasting the credential in by hand, it stopped working every time CodeTrellis restarted.
  - Re-add CodeTrellis from **Settings → MCP Server**: **Copy Claude Code command**, **Copy JSON**, or **Add to Claude Desktop…**. The new config holds no secret and keeps working across restarts.
- **For Claude Desktop:** open Claude Desktop once, then click **Add to Claude Desktop…** in CodeTrellis. Quit and reopen Claude Desktop afterwards so it picks up the change.
- **Using the Linux AppImage or the Windows portable `.exe`?** Connect agents from the `.deb`, `.rpm` or Windows installer where you can (see Known limits).
- **Pin the projects your agents work in.** Agents are trusted with your pinned projects and the 12 you opened most recently. When an agent is refused on an older project, the message now says so and how to fix it.
- **Update the phone companion** to approve work from your phone. No re-pairing is needed: pairing hasn't changed since 0.1.14. **Android:** `CodeTrellis-Companion-0.1.16.apk` is attached below; install it over the old one. **iOS:** build 26 has been submitted to TestFlight (invite-only) and shows up there once Apple finishes processing it.
- **The download is about twice the size.** The macOS DMG is about 340 MB, up from about 180 MB. The difference is a bundled engine that converts Word documents, decks and old-style spreadsheets on your machine.
- **Nothing new to switch on.** Every new agent tool is covered by the permissions agents already have, and a paired phone's permissions already cover approvals. Screen capture for agents is still off unless you turn it on.

## ✅ Acceptance criteria and sign-off

- **Every task can carry acceptance criteria:** what good looks like, in your words.
  - An agent submits evidence, and a person approves it or sends it back.
  - Sending work back always needs a note.
  - Rewording a criterion means earlier approvals no longer count.
- **Who can approve what is set per criterion.**
  - By default an agent can sign off its own code checks, such as "it compiles".
  - Everything else waits for a person, and you can require a person on any criterion.
  - Criteria an agent adds start as proposals, and only a person can change a criterion's policy.
- **Submissions are checked before they reach you.**
  - A submission is refused, and the agent told why, when it cites a sheet, cell, page, line, moment or quote that doesn't exist.
  - It's also refused for an output older than the task, a failing or out-of-date test report, or no change to the code the task names.
  - Anything that can't be checked is marked unverified rather than counted against the agent.
  - Whether the agent actually read the file is reported next to its submission.
- **Evidence is recorded and watched, never copied.**
  - The files a task used and produced are recorded with a fingerprint.
  - If one changes after you approved it, the approval goes stale and names the file.
  - A task that had passed your approval gate waits for you again.
- **Run checks.** "Run checks" on the plan page re-checks every criterion and tells you what changed since the last run. It never approves anything. When a source file changes, CodeTrellis re-checks the tasks that depend on it by itself.
- **Agents pick up what you sent back.** Their worklist carries your note and the exact cell or page you pointed at, so there's nothing to copy and paste into a chat.
- **The plan review lists every criterion under its task.** Each shows its state as a symbol and a word, never colour alone, plus who decided and a link to the evidence at the place it cites. Each task shows "N of M met". Deciding clears the matching "needs decision" notice, so the count stays true.
- **The PR draft says what was agreed:** each criterion, its evidence, and who signed. An agent's self-approval is labelled as one.
- **Sign-off pack.**
  - Save a plan's sign-off as a PDF or as a self-contained page from the Brief. PDF saving is desktop only.
  - Later, open the saved page in CodeTrellis to check that everything it vouches for still matches the files in that plan's project.
  - Decisions made on a phone name the paired device.

## 📄 Documents, not just code

- **A viewer for the files work depends on:**
  - PDFs, page by page.
  - Spreadsheets (`.xlsx`, `.xlsm`), with the cited cell highlighted. They show the values as last saved; macros never run, and a workbook with macros is badged.
  - Word documents and PowerPoint decks as pages, drawn by the bundled engine. If one can't be drawn, the viewer shows its text and says why.
  - Old-style `.xls` workbooks, through the engine.
  - HTML reports in their own sandbox, scripts off until you turn them on for that report.
  - Images; video, opened at the cited moment; CSV; and text or Markdown with the cited lines highlighted.
- **Send work back from the exact place:** a cell, a page or a line, straight from the viewer.
- **Show in Finder** is always there. CodeTrellis never opens a file in another app on your behalf.
- **The first Office file you open** shows "Preparing preview…" for a few seconds. After that, previews come from a cache.
- **The Brief:** a plan read as a piece of work.
  - It shows the tasks, the guide, the materials, what good looks like, and what the agent is doing, in plain words, e.g. "Read Q3-sales.xlsx — sheet Regional".
  - It needs no code graph and works in a folder with no git. A project can be set to open straight into the Brief.
- **Agents read materials safely.**
  - A workbook sheet by sheet, a Word document as text or as its pages, a deck slide by slide, a PDF page by page.
  - Each read runs in a separate, memory-capped process with no access to anything else, and is logged on the task.
- **Agents record what they used and made.** Materials, outputs and evidence are recorded against a task; these are the files the viewer shows and the checks look at.
- **Playbooks.**
  - Templates now bring their acceptance criteria, and there's one template chooser for everything.
  - A new **Analysis report** playbook runs Gather → Analyse → Draft → Review.
  - An empty plan can be filled from any template, and a template with placeholders asks for them first.
  - Publishing a plan as a template keeps its criteria but never their approvals.
- **New guide pages:** "For analysts" and "Connecting Claude Desktop".

## 📱 Phone

- **Approve or send back from your phone.** The notification opens the decision directly.
  - Evidence shows at the place it cites: a sheet's cells, an image, or text.
  - The next item waiting is one tap away.
- **An Approvals list** gathers everything waiting on you across plans. The home tab shows a "waiting for your approval" card, and task details have a Criteria section.
- **An approval whose file has changed** asks "Still met?".
- **Sending back needs a note.** The note can point at the file you're looking at.

## 🤖 Agents

- **Agents stay connected when CodeTrellis restarts,** and a second copy of CodeTrellis running on another port no longer confuses them.
- **Agents appear under their own name** — Claude Desktop, Cursor and so on — rather than a guess, and an agent is never mistaken for you.
- **Add to Claude Desktop** shows you exactly what will change and keeps a backup of Claude Desktop's config before writing it. Only you can trigger it, from the CodeTrellis window. Claude Desktop gets the same tools as any other agent.
- **Copy instructions for an agent** gives plain-English setup steps an agent can follow on its own. It contains no secret.
- **Point an agent at anything.** Every plan, task, comment, page and attachment has a short `#9f2c41ab` reference. Copy it, paste it to an agent, and it will know exactly what you mean.
- **Agents can show you things:** a file in the code reader, a task in the Brief, or a document at the place it cites.
- **Screenshots match the screen.** For agents you've allowed to capture the screen, screenshots are no longer one step behind, and an open HTML report is included instead of a blank box.
- **Agents can attach video.** A plan that fails to be made from a template now says so, rather than looking like it worked.

## 🔍 Code and review

- **One verdict per line in the code reader:**
  - aligned: planned and changed;
  - drifted: changed, but nobody asked;
  - outstanding: planned, not done yet.

  Deleted code shows as a visible gap, and hovering a line says why it's marked. A file the plan asked to change no longer gets a "Drift · unexpected" header.
- **The review panel** sits above the plan diff and is open by default. Each task expands to the files that landed or are still missing, each one a link, and file rows in the plan diff open the file.
- **Trace works both ways,** from a line to the task that wanted it and back again.
- **Plans across worktrees.** Switch plans from the plan page, and see plans on your other worktrees. Opening a worktree switches to its tab instead of opening a duplicate.
- **Graph:**
  - Large graphs pan smoothly again. They no longer freeze the window every 10 seconds when there are uncommitted changes, and each window draws only its own project.
  - A faster card style is the default. Glass is still available from the graph toolbar or Settings → Appearance, and your choice is remembered.
  - Zoomed-out changed cards fill with their status colour.
  - The Symbols view now actually shows symbols.
  - An empty graph says why: no connections, a filter hiding everything (with a Clear button), or a failed load (with Retry).
  - A graph scope set by an agent no longer leaves the canvas blank for the rest of the session.
- **Go to line** jumps to the line even when the window isn't in front.

## 🔒 Privacy and security

- **Your files are only read inside projects you have opened.** That covers everything CodeTrellis reads or imports for you: plans, attachments, documents. It never follows a link out of them.
- **The document engine can't reach anything.**
  - It is built from LibreOffice's own source in CI and contains no network code.
  - It is handed a document's bytes and hands back a preview. It can't open your files.
  - It only runs if every file in it matches fingerprints fixed in the app.
- **HTML reports open in their own sandbox:** a separate session, no network, and only the report's own folder.
- **The sign-off PDF** is printed with scripts off and every network request blocked.
- **Only a person can approve** a criterion that needs a person, on the desktop or on a phone you confirmed during pairing.
- **Add to Claude Desktop only works from the app's own window,** so an agent can't rewrite another app's settings.
- **Spell-check dictionaries ship with the app,** and Linux and Windows builds use only them, so spell-check no longer downloads dictionaries from Google. macOS uses the system spellchecker, as before.
- **Update checks can be turned off** in Settings → Updates. **Settings → Telemetry** lists exactly what leaves your machine, and when.
- **Every installer is built from the locked dependencies** and checked for the version it will report before release. An attached Android APK is covered by the same signed checksum file as the desktop builds.

## 🛠 Fixes

- Several task settings looked saved but weren't: the approval gate, routing, symbol targets, and the shared/local switch. They save now.
- The app reports the version it was built as. 0.1.15 reported itself as 0.1.14 and offered itself as an update.
- First launch no longer shows a sign-up form in place of the app. Your name and email are read from git.
- A plan imported from another clone, machine or worktree shows under the right project, and isn't re-imported on every scan.
- A teammate's plan updates arriving by `git pull` were sometimes never picked up. They are now.
- Log files are capped at 14 days and 50 MB a day. One install had reached 1.8 GB.
- An agent asked to hide the terminal hid the Plans panel instead, and hiding Plans left an empty space. Both are fixed.
- A long project list on the welcome screen scrolls.
- Notifications no longer cover the chip that restores a minimised plan, and the gaps between stacked notifications no longer block clicks.
- The "Shared" chip appears as soon as a plan is exported.
- Removing an uploaded attachment now says the file on disk is kept.
- Screen readers: Settings, the folder picker and the template picker behave as proper dialogs, Escape closes Settings, and the terminal tab's close button has a name.

## Known limits

- **Agent connections on the Linux AppImage and the Windows portable `.exe` have not been tested across restarts.** Both run from a temporary location that changes each launch, and the connector config points at it. Prefer the `.deb`, `.rpm` or Windows installer for agent work until this is confirmed.
- **Sign-offs stay on the machine where they were made.** Plan files carry the criteria but never the decisions, so a teammate who pulls the plan sees them unmet. A plan file can add or reword criteria but can never loosen them.
- **Shared tasks commit their conversation.** Comments, attachments and channel events on a shared task are written into the plan's files and committed with it. Set a task to Local to keep it off disk.
- **Removing an uploaded attachment** leaves the file on disk.
- **Materials must be inside an opened project.** Files elsewhere, or reached through a shortcut or link, are not shown or read.
- **Office previews:**
  - The first one takes a few seconds.
  - The engine uses about 1.3 GB of memory while it's running and stops after three idle minutes.
  - Line breaks can differ from Office's by a word.
  - Older `.doc` and `.ppt` files aren't previewed.
- **Word page numbers can't be checked,** because they depend on layout, so cite a quote instead.
- **Spreadsheets** show saved values only; nothing is recalculated.
- **The phone** shows images, text and tables, not rendered Office pages.
- **Spell-check:** only English dictionaries are bundled, so other languages get English spell-check.
- **Linux AppImage** runs without Chromium's sandbox. Prefer the `.deb` or `.rpm` where you have the choice.
- **Windows** builds are not code-signed, so SmartScreen may warn once.

## First launch

- **macOS:** drag to Applications and open. If you see "app is damaged" (usually because the download lost its attributes), run `xattr -cr /Applications/CodeTrellis.app` once.
- **Windows:** SmartScreen may warn once. Choose "More info", then "Run anyway".
- **Linux (AppImage):** `chmod +x CodeTrellis-0.1.16-x86_64.AppImage && ./CodeTrellis-0.1.16-x86_64.AppImage`
- **Linux (.deb / .rpm):** `sudo apt install ./codetrellis_*.deb` or `sudo dnf install ./codetrellis-*.rpm`
