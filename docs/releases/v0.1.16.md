CodeTrellis 0.1.16 is the evidence-and-sign-off release: agents now show their work against acceptance criteria a person approves, and CodeTrellis works for documents as well as code.

## ⚠️ Before you start

- **Reconnect your agents once.** Agent configs copied from earlier versions carried a key that changes every time CodeTrellis starts, so they broke on every restart. Re-add CodeTrellis from **Settings → MCP Server** (or **Add to Claude Desktop**). The new config holds no secret and keeps working across restarts.
- **Update the phone companion** to approve work from your phone. No re-pairing is needed: pairing is unchanged since 0.1.14. COMPANION: *which builds are in this release — e.g. "Android APK attached; iOS via TestFlight" — and say plainly if one is not.*
- **The download is larger.** Word documents and decks are now converted on your machine by a bundled engine, so nothing leaves it.

## ✅ Acceptance criteria and sign-off

- **Every task can carry acceptance criteria**, meaning "what good looks like". An agent submits evidence, and **only a person** can approve it or send it back with a note. An agent can approve its own work only on criteria you allow, such as "the code compiles".
- **Submissions are checked before they reach you.** Does the cell it cites exist? Did the agent actually read the file? Did the output change since the task started? If not, the agent is told why and has to fix it first.
- **Evidence is kept and watched.** Files a task used and produced are recorded with a fingerprint. If one changes after you approved it, the approval goes stale and names the file.
- **Agents pick up what you sent back.** Their worklist carries your note and the exact cell or page you pointed at, so there is nothing to copy and paste into a chat.
- **The PR draft says what was agreed:** each criterion, its evidence, and who signed. An agent's self-approval is labelled as one.
- **Sign-off pack:** save it as a PDF or a self-contained page. Later, verify from the file alone whether everything it vouches for still matches.

## 📄 Documents, not just code

- **A viewer for the files work depends on:**
  - PDF pages;
  - spreadsheets, with the cited cell highlighted;
  - Word documents and PowerPoint decks as pages;
  - HTML reports in a sandbox with scripts off;
  - images, video, CSV and Markdown.
  
  You can send work back from the exact cell or page.
- **The Brief:** a plan read as a piece of work — tasks, the guide, the materials, what good looks like, and what the agent is doing. It needs no code graph, and works in a folder with no git.
- **Agents can read materials safely.** They get a workbook sheet by sheet, a Word document as text, a deck slide by slide, and a PDF page by page. Files are read in a sandbox, and every read is logged on the task.
- **Playbooks:** templates now bring their acceptance criteria. There is a new **Analysis report** playbook (Gather → Analyse → Draft → Review), and one template chooser for everything.

## 📱 Phone

- **Approve or send back from your phone.** The notification opens the decision directly. Evidence shows at the place it cites: sheet cells, images or text. The next item waiting is one tap away.

## 🤖 Agents

- **Agents stay connected when CodeTrellis restarts**, and a second copy running on another port no longer confuses them.
- **Add to Claude Desktop** shows you the change and keeps a backup of Claude Desktop's config before writing it. Claude Desktop gets the full tool set.
- **Point an agent at anything.** Every plan, task and comment has a small `#9f2c41ab` reference you can copy and paste to an agent, and it will know exactly what you mean.

## 🔍 Code and review

- **One verdict per line in the code reader:** aligned (planned and changed), drifted (changed, nobody asked) or outstanding (planned, not done yet). Deleted code shows as a visible gap, and hovering a line says why it is marked.
- **Trace works both ways**, from a line to the task that wanted it and back.
- **Switch plans from the plan page**, and see plans on your other worktrees.
- **Graph:** a faster card style by default (Glass is still available). The Symbols view now actually shows symbols, and an absolute scope path no longer blanks the canvas.

## 🔒 Privacy and security

- **Spell-check dictionaries ship with the app**, so on Linux and Windows nothing is downloaded from Google any more.
- **Automatic update checks can be turned off** in Settings → Updates. **Settings → Telemetry** now lists exactly what leaves your machine, and when.
- **Recorded files and documents are read only inside your project**, never through links. Previews and conversions run with no network access.
- **Plan import is confined** to the projects you have opened, and only worktrees that belong to this repository are listed.

## 🛠 Fixes

- Several task settings looked saved and weren't: the approval gate, routing, symbol targets, and the shared/local switch. They save now.
- The app reports the version it was built as. 0.1.15 reported itself as 0.1.14 and offered itself as an update.
- Notifications no longer cover the chip that restores a minimised plan.
- A long project list on the welcome screen scrolls. "Hide the terminal" no longer hides the plans.

## Known limits

- **Spell-check:** only English dictionaries are bundled, so other languages get English spell-check. macOS uses the system spellchecker, as before.
- **Linux AppImage** runs without Chromium's sandbox. Prefer the `.deb` or `.rpm` where you have the choice.
- **Windows** builds are not code-signed, so SmartScreen may warn once.
- **Decks:** a deck the engine can't convert is shown as its slides' text, and the viewer says why.

## First launch

- **macOS:** drag to Applications and open. If you see an "app is damaged" warning (usually a download that stripped its attributes), run `xattr -cr /Applications/CodeTrellis.app` once.
- **Windows:** SmartScreen may warn once. Choose "More info", then "Run anyway".
- **Linux (AppImage):** `chmod +x CodeTrellis-0.1.16-x86_64.AppImage && ./CodeTrellis-0.1.16-x86_64.AppImage`
- **Linux (.deb / .rpm):** `sudo apt install ./codetrellis_*.deb` or `sudo dnf install ./codetrellis-*.rpm`
