# Phase 33 — Rules and clarity

Everything for Phase 33 is in this folder. From this phase on, each phase
has its own folder, `docs/phase-<n>/`, with the same files.

| File | What it is |
|---|---|
| [LOG.md](LOG.md) | **Read first.** Now, the checklist (generated), the baseline, decisions and dated entries |
| [STATUS.yaml](STATUS.yaml) | The steps as data. Edit it, then `npm run status` |
| [EXECUTION.md](EXECUTION.md) | How the work is run, the order of work, and a done-when for every step |
| [RULES-AND-CLARITY.md](RULES-AND-CLARITY.md) | The design: the rulebook, change control, checks anywhere, and the clarity fixes |
| [AGENT-CHECKS-AND-REVIEW.md](AGENT-CHECKS-AND-REVIEW.md) | Agent checks with nobody to talk to, the review features, and how rules and results are shown |

The owner follows progress on the page linked in EXECUTION §1.1, which
`npm run status:page` regenerates from STATUS.yaml and git.
