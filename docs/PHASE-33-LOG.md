## Decisions

- **2026-10-05 — Phase 33 is run like Phase 32** (the owner): an
  integration branch, one step per branch and PR, a generated log, and a
  progress page he can open.
- **2026-10-05 — Rules leave `config.json` and Settings** (the owner: "in
  SQL, JSON or some kind of YAML file that could exist or location"). The
  design proposes YAML files per suite under `.codetrellis/rules/` as the
  source, with SQLite as an index (design §3.1); confirm in §8.
- **2026-10-05 — Changing architecture enforcement is explicit** (the
  owner: "something which the user has to be explicit about"). Agents
  propose; a person confirms; loosening is signed and checked in CI
  against the base branch (design §4).
- **2026-10-05 — Checks run at any scope, locally and in CI**, the agent
  checks included (the owner: "check conformity of a particular suite not
  the whole thing"; "should also be able to run them locally").
- **2026-10-04 — Agent checks bring their own endpoint, model and API key
  or OAuth**, not tied to the repository host (the owner).
- **2026-10-05 — Clarity items in scope** (the owner): a colour legend on
  the graph and elsewhere; import edges on and off; the graph full screen
  and back; selecting a card shows its plan items beside "View source";
  opening a minimised plan maximises it.
- **2026-10-05 — Relief first, then safety.** Track S comes straight after
  Stage 0 (the freeze), then R1–R3 (a pull request can today weaken the
  rules that judge it), then the small clarity wins (EXECUTION §2).
